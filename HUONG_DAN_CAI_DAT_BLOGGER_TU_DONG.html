01

Chuẩn Bị Trang Blogger Mới & Lấy Blog ID

Tìm mã định danh duy nhất của blog của bạn để phần mềm biết cần đăng bài vào đâu.

  1. Truy cập vào trang quản trị Blogger: https://www.blogger.com.
  2. Tạo một blog mới (nếu chưa có) hoặc chọn đúng blog bạn muốn tự động hóa.
  3. Nhìn lên thanh địa chỉ của trình duyệt web (URL), bạn sẽ thấy một dãy số dài ở sau chữ /blog/posts/ hoặc /blog/settings/.
  4. Dãy số đó chính là BLOGGER_BLOG_ID của bạn. Hãy copy dãy số này lưu vào Notepad.

02

Bật Blogger API & Lấy Google OAuth (Client ID, Secret, Refresh Token)

Cấp quyền cho robot thay mặt bạn đăng bài và đặt lịch hẹn giờ lên Blogger.

  1. Truy cập Google Cloud Console: https://console.cloud.google.com và đăng nhập cùng tài khoản quản lý blog.
  2. Bấm Select a project (Chọn dự án) ➔ New Project (Dự án mới) ➔ Đặt tên Blogger-Auto-Cloud ➔ Nhấn Create.
  3. Vào thanh tìm kiếm trên cùng, gõ Blogger API v3 ➔ Bấm vào kết quả và nhấn nút Enable (Bật).
  4. Ở menu bên trái, vào APIs & Services ➔ OAuth consent screen (Màn hình đồng ý OAuth):
    • Chọn External (Bên ngoài) ➔ Bấm Create.
    • Điền tên ứng dụng (vd: Blogger Cloud Poster) và email của bạn ở các ô bắt buộc.
    • Bấm Save and Continue qua các bước cho đến khi hoàn tất.
    • Tại mục Test users (Người dùng thử nghiệm): bấm + Add Users và thêm chính địa chỉ Gmail của bạn vào.
  5. Ở menu bên trái, vào Credentials (Thông tin xác thực):
    • Bấm + Create Credentials ➔ Chọn OAuth client ID.
    • Mục Application type: chọn Desktop app (hoặc Web application).
    • Bấm Create. Google sẽ cấp cho bạn Client ID và Client Secret. Hãy copy 2 giá trị này lại.
  6. Lấy Refresh Token:
    • Chạy file get_refresh_token.py trên máy tính hoặc sử dụng công cụ Google OAuth 2.0 Playground.
    • Phạm vi quyền (Scope) cần tích chọn: https://www.googleapis.com/auth/blogger.
    • Cấp quyền xong, bạn sẽ nhận được chuỗi mã GOOGLE_REFRESH_TOKEN (dạng: 1//0gvjF...).

03

Lấy Google Gemini API Key (Bộ Não Viết Bài Miễn Phí)

Trí tuệ nhân tạo Gemini 2.5 Flash thông minh sẽ tự động sinh nội dung chuẩn SEO 1500+ từ.

  1. Truy cập trang Google AI Studio: https://aistudio.google.com/app/apikey.
  2. Đăng nhập tài khoản Google của bạn.
  3. Bấm nút Create API Key (Tạo khóa API).
  4. Chọn đúng dự án Google Cloud bạn vừa tạo ở Bước 2.
  5. Bấm Create API Key in existing project.
  6. Copy chuỗi khóa API bắt đầu bằng AIzaSy... lưu lại. Đây chính là GEMINI_API_KEY.

Mẹo nâng cao (Key Pool): Bạn có thể tạo 3 đến 5 khóa Gemini API Key từ các tài khoản Gmail khác nhau và điền cách nhau bằng dấu phẩy (KEY_1,KEY_2,KEY_3) vào biến GEMINI_API_KEYS để hệ thống xoay vòng tự động, không bao giờ lo hết hạn ngạch!
04

Tạo Telegram Bot & Nhóm Nhận Báo Cáo Tự Động

Mỗi khi có bài viết được lên lịch hay gửi Indexing thành công, điện thoại của bạn sẽ rung báo ngay lập tức.

  1. Mở ứng dụng Telegram trên điện thoại hoặc máy tính.
  2. Tìm kiếm bot chính thức: @BotFather.
  3. Gõ lệnh /newbot, đặt tên cho bot (vd: Blogger LuViet Bot) và đặt username kết thúc bằng bot (vd: my_luviet_blogger_bot).
  4. BotFather sẽ gửi cho bạn một chuỗi token dạng: 8480459173:AAHhSTEG.... Lưu lại làm TELEGRAM_BOT_TOKEN.
  5. Tạo một nhóm Telegram mới trên điện thoại (đặt tên vd: Báo Cáo Blogger) và mời con Bot vừa tạo vào nhóm.
  6. Thêm bot @RawDataBot hoặc @userinfobot vào nhóm để lấy số Chat ID của nhóm (thường là một dãy số âm bắt đầu bằng dấu trừ, ví dụ: -5074952407 hoặc -100...). Sau khi lấy xong Chat ID, bạn có thể xóa bot lấy ID ra khỏi nhóm.

05

Cấu Hình Google Sheets (Kho Đề Tài & Webhook Báo Cáo)

Nơi bạn nhập hàng trăm tiêu đề bài viết và tự động đổi màu xanh khi bài viết đăng thành công.

  1. Mở bảng tính Google Sheets kế hoạch bài viết của bạn. Đảm bảo cấu trúc cột như sau:
    • Cột A: Số Thứ Tự (STT)
    • Cột B: Tiêu Đề Bài Viết
    • Cột C: Từ Khóa SEO Chính
    • Cột D: Ý Định Tìm Kiếm (Search Intent)
    • Cột E: Nhóm Chuyên Mục (Labels, vd: dich-vu, tin-tuc)
    • Cột F: Link Ảnh Tùy Chọn (Nếu để trống robot sẽ tự tạo Thumbnail Doanh Nhân)
    • Cột G: Trạng Thái (Robot sẽ tự điền: Đã lên lịch hoặc Đã đăng và tô màu xanh lá)
    • Cột H: Ngày Lên Lịch / Xuất Bản
    • Cột I: Link Bài Viết Thực Tế
  2. Bấm nút Chia sẻ (Share) ở góc trên bên phải bảng tính ➔ Mục Quyền truy cập chung: chọn Bất kỳ ai có đường liên kết ➔ Chọn quyền Người xem (hoặc Người chỉnh sửa) ➔ Sao chép liên kết này lưu làm GOOGLE_SHEET_URL.
  3. Cài đặt Webhook tự động cập nhật bảng tính:
    • Trên thanh menu Google Sheets, bấm Tiện ích mở rộng (Extensions) ➔ Apps Script.
    • Xóa sạch code mặc định, copy toàn bộ mã nguồn trong file google_sheets_webhook.js dán vào.
    • Nhấn biểu tượng chiếc đĩa mềm để Lưu (Save).
    • Bấm nút Triển khai (Deploy) ở góc trên bên phải ➔ Bản triển khai mới (New deployment):
      • Chọn loại: Ứng dụng web (Web app).
      • Mô tả: Blogger Webhook v1.
      • Thực thi dưới dạng (Execute as): Tôi (Tài khoản của bạn).
      • Ai có quyền truy cập (Who has access): Bất kỳ ai (Anyone).
    • Nhấn Triển khai (Deploy) ➔ Google sẽ cấp cho bạn một đường dẫn Web App kết thúc bằng /exec.
    • Copy đường link này lưu làm GOOGLE_SHEET_WEBHOOK_URL.
Ảnh minh họa 05
Giao Diện Triển Khai Web App Trên Google Apps Script
(Chụp cửa sổ New Deployment với quyền "Anyone" và khung sao chép URL kết thúc bằng /exec)
⚠️
LƯU Ý CỰC KỲ QUAN TRỌNG: Tuyệt đối KHÔNG bấm vào mục "Bộ kích hoạt (Triggers - biểu tượng đồng hồ)" trong Apps Script để thêm trigger "Khi chỉnh sửa (On edit)". Webhook chạy độc lập qua link Web App, thêm trigger edit sẽ làm Google hiểu nhầm và gửi email báo lỗi máy chủ!
06

Cấu Hình Google Indexing API (Lập Chỉ Mục Siêu Tốc)

Tự động bắn URL bài viết đã Live lên thẳng Google Bot để bài viết xuất hiện trên kết quả tìm kiếm Google chỉ sau vài phút.

  1. Quay lại Google Cloud Console: https://console.cloud.google.com.
  2. Tìm kiếm Web Search Indexing API ➔ Bấm vào và nhấn nút Enable (Bật).
  3. Vào IAM & Admin ➔ Service Accounts (Tài khoản dịch vụ) ➔ Bấm + Create Service Account.
    • Đặt tên tài khoản: blogger-indexing-bot ➔ Nhấn Create and Continue ➔ Nhấn Done.
    • Bạn sẽ thấy một địa chỉ email robot dạng: blogger-indexing-bot@du-an.iam.gserviceaccount.com. Hãy copy email này lại.
  4. Bấm vào email Service Account vừa tạo ➔ Chuyển qua tab Keys (Khóa) ➔ Bấm Add Key (Thêm khóa) ➔ Create new key ➔ Chọn định dạng JSON ➔ Nhấn Create.
    • Một file đuôi .json sẽ được tải xuống máy tính của bạn.
    • Mở file này bằng Notepad, chọn Ctrl + A và Ctrl + C để copy toàn bộ nội dung file JSON này.
  5. Phân quyền trong Google Search Console:
    • Truy cập Google Search Console của website Blogger của bạn.
    • Vào menu Cài đặt (Settings) ➔ Người dùng và quyền (Users and permissions).
    • Bấm nút Thêm người dùng (Add user) ➔ Dán địa chỉ email robot của Service Account ở trên vào ➔ Phân quyền: Chủ sở hữu (Owner) ➔ Nhấn Thêm (Add).
Ảnh minh họa 06
Thêm Email Service Account Làm Chủ Sở Hữu (Owner) Trong Google Search Console
(Chụp màn hình Settings > Users and permissions > Thêm email robot với quyền Owner)
07

Fork Mã Nguồn & Cài Đặt 9 Khóa Bí Mật Vào GitHub Secrets

Lưu trữ an toàn tuyệt đối các thông tin đăng nhập, không ai có thể xem trộm được mật khẩu của bạn.

  1. Đăng nhập tài khoản GitHub của bạn: https://github.com.
  2. Truy cập vào kho lưu trữ mã nguồn của hệ thống và nhấn nút Fork (hoặc Clone về tài khoản của bạn).
  3. Vào kho repository của bạn trên GitHub ➔ Bấm vào tab Settings ở thanh menu trên cùng.
  4. Ở cột bên trái, tìm mục Secrets and variables ➔ chọn Actions.
  5. Bấm nút màu xanh New repository secret để lần lượt thêm 9 biến sau:
Tên Secret (Gõ chính xác) Giá trị cần điền vào
BLOGGER_BLOG_ID Dãy số ID blog lấy ở Bước 1.
GEMINI_API_KEY Khóa Gemini API lấy ở Bước 3 (bắt đầu bằng AIzaSy...).
GOOGLE_CLIENT_ID OAuth Client ID lấy ở Bước 2 (...apps.googleusercontent.com).
GOOGLE_CLIENT_SECRET OAuth Client Secret lấy ở Bước 2.
GOOGLE_REFRESH_TOKEN Refresh Token Blogger lấy ở Bước 2 (bắt đầu bằng 1//0...).
GOOGLE_SHEET_URL Đường link chia sẻ file Google Sheets ở Bước 5.
GOOGLE_SHEET_WEBHOOK_URL Đường link Web App Apps Script đuôi /exec ở Bước 5.
TELEGRAM_BOT_TOKEN Chuỗi Token bot từ @BotFather ở Bước 4.
TELEGRAM_CHAT_ID Dãy số Chat ID nhóm nhận báo cáo ở Bước 4 (ví dụ: -5074952407).
INDEXING_SERVICE_ACCOUNT_JSON Toàn bộ nội dung file JSON tải về ở Bước 6 (bắt đầu từ dấu { đến dấu }).
Ảnh minh họa 07
Danh Sách Các Biến Môi Trường Trong GitHub Repository Secrets
(Chụp giao diện Settings > Secrets and variables > Actions hiển thị danh sách các Secret đã nhập)

Bấm Chạy Thử Nghiệm & Tận Hưởng Thành Quả

Kích hoạt lần đầu tiên bằng tay và ngắm nhìn robot làm việc hoàn toàn tự động.

  1. Trên repository GitHub của bạn, bấm vào tab Actions trên cùng.
  2. Ở cột bên trái, bấm chọn quy trình: 🤖 Tự Động Viết & Đăng Bài Blogger Chuẩn SEO.
  3. Bạn sẽ thấy một thanh thông báo màu xanh/xám có nút Run workflow ở bên phải:
    • Bấm nút Run workflow.
    • Giữ nguyên nhánh main và bấm nút xanh Run workflow.
  4. Chờ khoảng 1-2 phút:
    • Một vòng tròn màu vàng xoay tròn và đổi sang màu xanh lá cây (Success ✓).
    • Điện thoại của bạn sẽ báo ting ting trên Telegram thông báo bài viết đã được lên lịch thành công!
    • Mở Google Sheets ra kiểm tra: dòng đề tài vừa chọn đã được tô màu xanh lá, có ngày giờ lên lịch và link bài viết!
    • Mở trang quản trị Blogger mục Đã lên lịch (Scheduled): bài viết đã sẵn sàng với hình Thumbnail Doanh Nhân YouTube sắc nét!
    • Vào đúng giờ xuất bản, robot quét bài thấy HTTP 200 Live sẽ tự động bắn Indexing lên Google Search Console ngay lập tức!
